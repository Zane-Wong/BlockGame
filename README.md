# 魔改俄罗斯方块

> **作者** wangzhuo　·　**联系方式** mail_zhuo@163.com
> Copyright © 2026 wangzhuo. All rights reserved.

重构操作层的俄罗斯方块。核心创新在**单指手势**——不用虚拟按键，滑动、拖拽、长按各自对应一种操作。

纯 H5 + Canvas 单页，无构建、无依赖，浏览器直接打开即可玩。引擎为纯 JS，后续可平移到小程序 Canvas 2D。

## 运行

```bash
# 直接打开
start index.html

# 或起个静态服务（推荐，避免 file:// 的限制）
python -m http.server 8848
# 然后访问 http://127.0.0.1:8848/index.html
```

## 操作

| 手势 | 效果 |
|---|---|
| 左右滑动 | 方块逐格横移，跟手 |
| 向上滑动 | 旋转。偏左逆时针，偏右顺时针 |
| 按住方块拖到目标列 | 松手后自动寻路就位（BFS 路径规划） |
| 长按空白处蓄力，松手 | 弹射当前方块，力度由蓄力时长决定 |

键盘（桌面调试）：方向键移动/软降，`Z`/`X` 旋转，空格硬降，`P` 暂停。

## 结构

```
index.html          页面外壳、CSS、UI 层与启动逻辑
src/
├── core.js         棋盘、方块、SRS 旋转与踢墙、7-bag、BFS 寻路
├── gesture.js      单指手势状态机（意图分流：移动/旋转/导航/蓄力）
├── render.js       Canvas 渲染：棋盘、幽灵块、导航预览、弹弓 UI
├── fx.js           粒子、震屏、WebAudio 实时合成音效
└── game.js         主循环、游戏状态机、布局与响应式
```

设计要点：

- **手势判定与事件绑定分离**——`gesture.js` 的判定部分是纯函数，移植小程序只需替换事件绑定层。
- **导航预览即执行结果**——BFS 直接返回终点坐标，预览轮廓与实际落点严格一致，不存在"看到的和落下的不一样"。
- **无外部资源**——音效由 WebAudio 实时合成，图形全部程序化绘制。
